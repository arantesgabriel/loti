## Observações relevantes

1. Alguns **nomes de arquivos** conservam sufixos históricos como `_EM_REVISAO` ou `_REVISAO`. **O status correto é o descrito dentro de cada documento** e neste manifesto: Anexos C e D aprovados; Fase 6 encerrada; Fase 7 aberta.
2. A pasta de fontes históricas contém somente os artefatos disponíveis neste pacote. Arquivos completos das Fases 1, 3 e 5 não estavam disponíveis localmente na montagem e não foram fabricados; suas decisões foram herdadas e consolidadas nos registros posteriores.
3. Não há capturas definitivas da conta demonstrativa nem assets 3D finais neste pacote. Devem ser obtidos posteriormente de modo seguro e autorizado.
4. O Copy Deck inclui textos condicionais a disponibilidade real do produto; **aprovação de copy não significa autorização para publicação de funcionalidades futuras**.
5. O prompt exige **documentação e plano**, não implementação, alteração de banco, migração, deploy ou publicação.
